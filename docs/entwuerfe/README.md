# Entwürfe „Neuer Look“

Gewählte Entwürfe (Stand 10.10.2026) als HTML-Dateien zum Nachschlagen für die Umsetzung (Paket L, siehe
[`../DESIGNSYSTEM.md`](../DESIGNSYSTEM.md)). Alle Texte, Namen und Zahlen sind Beispiele (Eltern mit zwei Kindern,
SV Grün-Weiß, hell; `HomeDark` dunkel). Jede Datei ist eine eigenständige Seite im Handyformat (390 pt breit) und lässt
sich im Browser öffnen; Schriften kommen von Google Fonts (Oswald, Open Sans). Die Seiten sind Entwürfe, kein App-Code.

| Datei                                         | Inhalt                                                           |
| --------------------------------------------- | ---------------------------------------------------------------- |
| `HomeFinal.html`                              | Home: Spiele, Offen, Deine Woche, Neuigkeiten, Schnellzugriff    |
| `TeamNeu.html`                                | Team: Team-Kacheln, Kopfband, Kacheln, Termin, Ergebnisse        |
| `TermineNeu.html`                             | Termine: Filter, Als Nächstes, Kalender, Tag                     |
| `VereinNeu.html`                              | Verein: Vereinstermin, Kacheln, Anlage heute, News               |
| `MehrNeu.html`                                | Mehr: Profilkarte, Kinder, Mein Bereich, Mannschaften, Einstellungen |
| `HomeDark.html`                               | Home im Dunkelmodus (Flächenstufen, dunkle Chips)                |
| `ZustandLaden/Offline/Leer/Fehler.html`       | Platzhalter, Offline-Hinweis, leere Zustände, Fehler/Warnung/Toast/Bestätigung |

Der Menüpunkt heißt weiter „Mehr“ (der Entwurf `HomeDark` zeigt noch „Profil“ als verworfene Idee).

# Clubroof

> „Dein Verein unter einem Dach.“

Clubroof ist eine Vereins-App für iOS und Android, die Vorstand, Trainer, Eltern und Spieler eines Sportvereins
an einem Ort zusammenbringt: Termine & Zusagen, Teams, Vereinsleben, Ehrenamt, Kasse, Dokumente und Verwaltung.
